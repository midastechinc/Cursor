# Midas Payroll Desktop Build

This project can run as a desktop app and be installed like regular software.

## What is implemented

- Electron desktop shell with installer packaging (Windows NSIS).
- Local API server starts inside the app.
- Persistent database path outside the install folder so updates do not erase user data.
- Startup migrations for employee records (adds `terminationDate` to existing records automatically).

## Data persistence and updates

- In production, the database is stored in:
  - `%APPDATA%\Midas Payroll\data\payroll.sqlite`
- The installer updates app binaries, but keeps this user data folder intact.
- On startup, migration logic updates stored records safely without deleting clients/settings/pay runs.

## Build installer (Windows)

```bash
npm install
npm run desktop:build
```

Installer output:

- `release/` folder
- `.exe` installer generated by `electron-builder`

## Run desktop app in development

```bash
npm install
npm run desktop:dev
```

This starts Vite + API + Electron together.

## Auto-update setup (GitHub Releases)

Auto-update is wired into the desktop app using `electron-updater`. To enable it:

1. Create a GitHub token with `repo` scope.
2. Set `GH_TOKEN` in your shell/CI.
3. Build and publish from Windows:

```bash
npm install
npm run desktop:publish
```

The app checks for updates on startup and every 6 hours. When an update is downloaded, users get a restart prompt.  
User data remains intact because the SQLite file is outside the install directory.

## Notes

- Publishing must run from Windows for Windows installers.
- This Linux cloud environment cannot complete Windows signing/build steps that require Wine.
